# Marketing collateral

This directory holds auxiliary marketing artifacts that are **not** part of the public marketing site at askloremaster.com.

These are standalone outputs (PDFs, flyers, decks, social assets) built for outreach, events, and physical handouts.

## What's here

- `flyers/lgs-pilot/` — One-page flyer for local game store outreach during the pilot program.

## Conventions

- Each artifact lives in its own folder with everything needed to build it (HTML, build script, README).
- Build outputs go to a local `dist/` inside each artifact folder. These are git-ignored.
- Shared assets (fonts, logos) are pulled from the main site's `public/` directory so brand stays in sync.
